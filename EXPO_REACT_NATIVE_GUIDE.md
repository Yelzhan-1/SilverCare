# SilverCare — Руководство по запуску и архитектуре для Хакатона

**SilverCare** — мобильное приложение напоминания о приёме лекарств для пожилых людей с подтверждением в **ОДИН КЛИК**.

---

## 2. Команды для установки и запуска

### Веб-версия (Live Sandbox / Chrome / Safari):
```bash
npm install
npm run dev
```
Откройте в браузере `http://localhost:3000`.

### React Native / Expo проект:
Для сборки автономного Expo-приложения на смартфон:
```bash
npx create-expo-app silvercare-native --template blank-typescript
cd silvercare-native
npx expo install expo-notifications expo-speech @react-native-async-storage/async-storage lucide-react-native
```
Копируются модули из `src/`, где:
- `speechService.ts` использует `Speech.speak(text, { language: 'ru-RU', rate: 0.85 })`
- `audioAlarmService.ts` использует `expo-av` Sound с зацикливанием мелодии
- `storageService.ts` использует `AsyncStorage`
- Запуск на реальном телефоне через Expo Go:
```bash
npx expo start
```
Сканируйте QR-код приложением **Expo Go** на iOS или Android.

## 3. Как протестировать Демо-режим (Demo Mode) для жюри

1. Откройте приложение: вы увидите экран **«Сегодня»**:
   - Блок **«Следующий приём»**: 14:00, **АМЛОДИПИН**, 1 таблетка, «через 24 минуты».
   - Список **«Сегодня»**:
     - `✓ 08:00` Амлодипин, Принято в 08:02
     - `✓ 12:00` Витамин D, Принято в 12:01
     - `○ 14:00` Метформин, Следующий приём
     - `○ 20:00` Лозартан
2. Нажмите на иконку шестерёнки в правом верхнем углу (панель для жюри и родственников).
3. Нажмите кнопку **«Запустить демонстрацию через 10 секунд»** (или «Запустить немедленно»).
4. Наблюдайте таймер обратного отсчёта.
5. Ровно через 10 секунд срабатывает полный цикл:
   - Включается звуковой будильник (гармонический сигнал, оптимизированный для пожилого слуха).
   - Голос чётко произносит: **«Время принять лекарство. Амлодипин. Одна таблетка.»**
   - Появляется полноэкранный экран тревоги с огромной кнопкой **«✓ Я ПРИНЯЛ»**.
6. Нажмите **«✓ Я ПРИНЯЛ»** ровно **один раз**:
   - Будильник и голос мгновенно останавливаются.
   - Срабатывает тактильный отклик (haptic vibration) и победный аккорд.
   - Появляется зелёная анимация «Лекарство принято».
   - Запускается короткая **«Тренировка памяти»** («Запомните эти предметы»: 🍎 🔑 🚗).
   - Ответьте на вопрос («Какой предмет вы видели?»).
   - Появляется «Отлично!», и приложение автоматически возвращается на экран «Сегодня».
7. В списке лекарство отмечено **зелёной галочкой с точным временем подтверждения** (`Принято в HH:MM`).

## 4. Ограничения мобильных ОС (OS Limitations)

- **iOS Background Audio / Full-screen Alarm**:
  На iOS стандартные push-уведомления не могут самопроизвольно развернуть стороннее приложение на полный экран при заблокированном телефоне без специального VoIP / Critical Alerts разрешения от Apple. В MVP реализовано воспроизведение через Critical Notification + мгновенный переход на полноэкранный `AlarmScreen` при разблокировке или открытом приложении.
- **Android Full-Screen Intent**:
  На Android 14+ показ полноэкранного окна будильника поверх экрана блокировки требует системного разрешения `USE_FULL_SCREEN_INTENT`. В сборке Expo это настраивается через плагин `android.permission.USE_FULL_SCREEN_INTENT`.
- **Автовоспроизведение звука в браузерах**:
  Браузеры блокируют первый звук до первого взаимодействия пользователя со страницей. В приложении нажатие на кнопку запуска Демо или первый клик по экрану мгновенно активирует Web Audio Context.

## 5. Полностью работающий функционал

- ✅ **Подтверждение в один клик («✓ Я ПРИНЯЛ»)** без лишних диалогов «Вы уверены?».
- ✅ **Голосовое озвучивание на русском языке** с замедленной артикуляцией (0.85 rate).
- ✅ **Повторное прослушивание** кнопкой «🔊 ПРОСЛУШАТЬ ЕЩЁ РАЗ».
- ✅ **Звуковой будильник** на базе Web Audio API синтезатора средних частот.
- ✅ **Экран «Сегодня»** с карточкой «Следующий приём» и автоматическими галочками.
- ✅ **Локальное сохранение (Persistence)**: состояние остаётся сохранённым после перезагрузки.
- ✅ **Тренировка памяти**: рандомизированные наборы предметов и автоматический возврат.
- ✅ **Добавление лекарств**: возможность добавлять новые препараты, время, дозировку и формы.
- ✅ **Режим демонстрации для жюри (10 секунд / мгновенно)** с обратным отсчётом.
- ✅ **Кнопка сброса к эталонному демо-состоянию**.
- ✅ **Дизайн для пожилых**: кнопки >64px, контрастные цвета, отсутствие сложных меню, поддержка рамки смартфона.
