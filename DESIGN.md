# SilverCare — Design System (Claymorphism, senior-friendly)

Статус: Волна 1. Применено к главному экрану пожилого (`TodayScreen`, `NextMedicationCard`,
`MedicationListItem`), `AlarmScreen`, soft memory-баннеру и `RoleSwitcherModal` / кнопке «Ещё».
Остальные экраны (опекун, настройки, доп. модалки памяти) сознательно оставлены в прежнем
iOS-стиле — переедут на токены отдельной волной, чтобы этот PR оставался маленьким и обозримым.

## Зачем Claymorphism, а не Neumorphism

Классический neumorphism («мягкий UI» с одноцветным фоном+поверхностью и едва заметными
тенями) **не подходит** для пожилых пользователей — он специально малоконтрастный.
Claymorphism берёт ту же идею мягкого, объёмного «глиняного» слоя, но:

- поверхности имеют **насыщенный, различимый цвет** (не сливаются с фоном);
- текст — **высокий контраст** (тёмные чернила на светлой глине, белый на насыщенном primary);
- тени мягкие и толстые, дают ощущение «вылепленной» кнопки, но не в ущерб читаемости;
- никаких дешёвых AI-градиентов «в лоб» и мелкого серого текста (12px и ниже — только для
  некритичных бейджей, никогда для основного текста/чисел приёма лекарств).

## Токены (`src/index.css`, `@theme`)

Все токены — нативная Tailwind v4 CSS-конфигурация (`@theme`), поэтому доступны как обычные
утилиты: `bg-clay-primary`, `text-clay-ink`, `rounded-clay-lg`, `shadow-clay-raised` и т.д.
Никаких хардкод-хексов в новых компонентах.

### Цвет

| Токен | Значение | Назначение |
|---|---|---|
| `--color-clay-bg` | `#F1EEE7` | Фон страницы — тёплый, спокойный, без «больничной» синевы и без глянцевого белого. |
| `--color-clay-surface` | `#FBF9F5` | Основная поверхность карточек (чуть светлее фона — карточка «приподнята»). |
| `--color-clay-surface-sunken` | `#E9E4D9` | «Утопленные» элементы: инпуты, селекты, области ввода. |
| `--color-clay-ink` | `#211F1A` | Основной текст. Контраст на `clay-surface` ≈ 15.8:1 (AAA). |
| `--color-clay-ink-soft` | `#5B564B` | Вторичный текст/лейблы. Контраст на `clay-surface` ≈ 6.1:1 (AA даже для мелкого текста). |
| `--color-clay-primary` | `#2F5FD1` | Главный акцент (голос, ссылки, вторичные кнопки). |
| `--color-clay-primary-ink` | `#12306F` | Тёмный вариант primary (текст на светлом primary-фоне). |
| `--color-clay-success` | `#1E8F5E` | Приём лекарства подтверждён / кнопка «Я принял». |
| `--color-clay-danger` | `#D9503A` | Тревога / SOS / пропущено. Тёплая терракота, не «кровавый» красный. |
| `--color-clay-warning` | `#C97F1E` | Отложено (snooze). |

### Радиусы

| Токен | Значение |
|---|---|
| `--radius-clay-sm` | `18px` — мелкие чипы/бейджи |
| `--radius-clay-md` | `24px` — плитки, элементы списка |
| `--radius-clay-lg` | `32px` — карточки, модалки |
| `--radius-clay-xl` | `40px` — hero-карточка, alarm-карточка |

### Тени («глина»)

| Токен | Назначение |
|---|---|
| `--shadow-clay-raised` | Крупная приподнятая поверхность (hero-карточка, alarm-модалка). Мягкая внешняя тень + тонкий внутренний блик сверху. |
| `--shadow-clay-raised-sm` | То же, но легче — плитки, элементы списка. |
| `--shadow-clay-pressed` | Нажатое/активное состояние — внутренняя тень («вдавили глину»). Используется на `:active`. |
| `--shadow-clay-primary` / `-success` / `-danger` | Цветная тень под соответствующую кнопку (голубая/зелёная/терракотовая), чтобы кнопка «светилась» своим цветом, а не generic серым. |

## Типографика (senior-large)

- Главное число/действие (`hero`-заголовок лекарства): **28–36px**, `font-black`.
- Первичная кнопка: **20–24px**, `font-bold`, высота ≥ 64px (hit-area ≥ 3 см).
- Тело/подписи: **≥14px**. Не используем `text-[10px]`/`text-[11px]` для содержательного текста —
  только для второстепенных декоративных меток, и то с контрастом `clay-ink-soft`, не блёклым серым.
- `line-height` увеличен (`leading-tight`/`leading-relaxed`) — легче отслеживать строку взглядом.

## Формы / hit-areas

- Все интерактивные элементы на экране пожилого — **минимум 44×44px** (обычно 56–110px).
- Один явный primary action на экране (см. `NextMedicationCard`) — второстепенные действия
  визуально «тише» (меньше насыщенность, меньше тень).

## Motion / `prefers-reduced-motion`

Глобальный `@media (prefers-reduced-motion: reduce)` в `src/index.css` отключает/сокращает
все `animation`/`transition` до почти нуля для пользователей, которые выбрали «уменьшить
движение» в ОС — актуально для пожилых с вестибулярной чувствительностью.

## Что НЕ трогали в этой волне

- `CaregiverSettingsModal`, `CaregiverDashboardScreen`, `DemoControlPanel`, `MemoryGame`,
  `MemorySuiteModal` и остальные модалки — остаются на старой iOS-палитре. Переезд на clay-токены
  запланирован отдельной волной, чтобы не делать один гигантский PR.
- Нижние табы/вкладки **не возвращали** — кейс их запрещает для экрана пожилого.
