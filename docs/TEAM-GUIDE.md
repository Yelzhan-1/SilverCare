# SilverCare — гайд для команды

**Production:** https://silvercare-six.vercel.app  
**Локально:** http://127.0.0.1:3000/  
**Демо-аккаунты:** файл на рабочем столе `SilverCare-DEMO.txt` (не коммитится)

## Сценарий презентации (~3–4 мин)

### Подготовка
1. Два телефона / два окна Chrome (обычное + инкогнито).
2. Android Chrome предпочтительнее для push.
3. Войти подопечный + опекун из DEMO.txt (уже связаны).
4. У опекуна: разрешить уведомления.
5. Запасной план: «Ещё → Демо для жюри».

### Показ
1. **Подопечный** — приветствие, «Всё в порядке», 4 плитки.
2. **Лекарство** — «Я принял» (опционально демо эскалации LOW/MED/HIGH).
3. **SOS** — timeout 15с без отмены → у опекуна карточка (+ push если вкладка закрыта).
4. **Игра** — 20–30 сек.
5. **Опекун** — связь, пропуски, история, позвонить.

Сказать: «Это не вызов скорой. Данные в базе, Realtime и push — настоящие.»

## Слова (~40 сек)
«SilverCare помогает пожилому человеку не пропускать лекарства и быстро позвать близких. На главном экране всё крупно. Если нажать SOS и не ответить „я в порядке“, опекун получает тревогу на телефон — через базу и Web Push. Мы не пишем „скорая вызвана“ и не ставим диагнозов.»

## Q&A
- **Скорая?** Нет, только семья.
- **Связь?** Email + код приглашения в Supabase.
- **Нет сети?** Честно: онлайн-уведомления недоступны.
- **Падение/ночь?** Помощник, не диагноз.
- **Стек?** React + Supabase + Web Push.

## Не показывать на демо
- Sync списка лекарств между телефонами (каталог пока localStorage).
- Два alarm одновременно (очередь упрощена).
