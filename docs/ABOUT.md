# SilverCare — описание продукта

**Production:** https://silvercare-six.vercel.app

**SilverCare** — веб-приложение для пожилых людей и их родственников.

### Для подопечного
- Крупный главный экран без вкладок
- Напоминания о лекарствах с подтверждением в один клик и откладыванием
- SOS: 15 секунд «Вы в порядке?» → тревога близким
- Игра на память (парные карты)
- Экран «Состояние» (датчик движения / ночной stub без диагноза)

### Для опекуна
- Связь по коду приглашения
- Живые тревоги (Realtime) и Web Push
- Пропуски приёма и история
- Быстрый звонок

### Принципы
Честность: нет фейкового push, нет «скорая вызвана», нет меддиагнозов.
Стек: React + Vite + Tailwind + Supabase + Web Push.
